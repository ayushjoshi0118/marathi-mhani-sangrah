# मराठी म्हणी संग्रह — Marathi Mhani Sangrah

> **"मराठी संस्कृतीचा अनमोल ठेवा, जगासाठी खुला."**  
> *A living digital library of Marathi wisdom, language, culture, and everyday knowledge.*

---

## 📖 प्रकल्प परिचय (Overview)

**मराठी म्हणी संग्रह** हे मराठी भाषेतील पिढ्यान्‌पिढ्या चालत आलेल्या मौखिक लोकज्ञानाचा, जीवनमूल्यांचा आणि भाषिक सौंदर्याचा एक आदरपूर्वक, आधुनिक आणि अधिकृत डिजिटल ज्ञानकोश आहे.

हा केवळ साधा डेटाबेस किंवा तात्पुरता प्रकल्प नसून, जगभरातील मराठी भाषक, विद्यार्थी, शिक्षक, लेखक, संशोधक आणि नवीन पिढीसाठी तयार केलेले एक विश्वासार्ह, जाहिरातमुक्त आणि कायमस्वरूपी संदर्भ व्यासपीठ आहे.

- **प्रारंभिक प्रमाणित संग्रह:** तंतोतंत **१,००० अस्सल मराठी म्हणी**
- **कायमस्वरूपी अनुक्रमांक:** `#१` ते `#१०००` (सॉर्टिंग, फिल्टरिंग किंवा शोध घेतल्यावर कधीही बदलत नाहीत)
- **द्विभाषिक सुलभता:** प्रत्येक म्हणीचा सोपा मराठी अर्थ, इंग्रजी अनुवाद, मराठी व इंग्रजी उदाहरण, सांस्कृतिक संदर्भ आणि समतुल्य इंग्रजी म्हण

## ✨ प्रमुख वैशिष्ट्ये (Key Features)

### १. अस्सल १,००० म्हणींचे डिजिटल संवर्धन
- प्रत्येक नोंदीमध्ये:
  - मूळ मराठी म्हण (देवनागरी)
  - युनिक व स्थिर अनुक्रमांक (`#1` to `#1000`)
  - युनिकोड NFC नॉर्मलाइज्ड सर्च स्ट्रिंग
  - सोपा मराठी अर्थ
  - इंग्रजी अनुवाद (English Meaning)
  - दैनंदिन जीवनातील व्यावहारिक मराठी उदाहरण
  - इंग्रजी उदाहरण (English Example Translation)
  - सांस्कृतिक संदर्भ व वापराची परिस्थिती (Cultural Context)
  - समतुल्य इंग्रजी म्हण (English Equivalent)
  - १६ सांस्कृतिक वर्गवाऱ्यांपैकी एक मुख्य वर्गवारी
  - संबंधित टॅग्ज (Thematic Tags)
  - संपादकीय पडताळणी माहिती (Editorial Review Metadata)

### २. १६ सांस्कृतिक वर्गवाऱ्या (Curated Categories)
1. **शहाणपण आणि व्यवहारज्ञान** (*Wisdom & Practical Sense*)
2. **मेहनत आणि कष्ट** (*Labor & Hard Work*)
3. **कुटुंब आणि समाज** (*Family & Society*)
4. **पैसा आणि व्यवहार** (*Money & Trade*)
5. **स्वभाव आणि वर्तन** (*Human Nature & Conduct*)
6. **निसर्ग आणि शेती** (*Nature & Agriculture*)
7. **नशीब आणि प्रयत्न** (*Fate & Effort*)
8. **वेळ आणि संधी** (*Time & Opportunity*)
9. **सावधगिरी** (*Caution & Prudence*)
10. **सत्य आणि न्याय** (*Truth & Justice*)
11. **विनोद आणि उपरोध** (*Humor & Satire*)
12. **अनुभव आणि जीवन** (*Life Experience*)
13. **मैत्री आणि नाती** (*Friendship & Bonds*)
14. **शिक्षण आणि ज्ञान** (*Learning & Knowledge*)
15. **नेतृत्व आणि निर्णय** (*Leadership & Decisions*)
16. **भाषा आणि संवाद** (*Language & Dialogue*)

### ३. आजची म्हण (Deterministic Proverb of the Day)
- `Asia/Kolkata` टाईमझोनवर आधारित कॅलेंडर-लॉक्ड अल्गोरिदम.
- एकाच दिवशी सर्व वापरकर्त्यांना एकच प्रमाणित म्हण दिसते, रिफ्रेश केल्यावर बदलत नाही.
- मागील ६ दिवसांचा ऐतिहासिक संग्रह उपलब्ध.

### ४. ५ परस्परसंवादी ज्ञानखेळ (Interactive Learning Games)
1. **म्हण ओळखा (Guess the Proverb):** अर्थ व संदर्भावरून योग्य म्हण ओळखा (कॉन्फेटी सेलिब्रेशनसह).
2. **रिकामी जागा भरा (Fill in the Blanks):** म्हणीतील योग्य शब्द निवडून वाक्य पूर्ण करा.
3. **योग्य अर्थ निवडा (Select Meaning):** बहुपर्यायी चाचणीतून अचूक अर्थ निवडा.
4. **म्हण जुळवा (Match the Pairs):** ४ म्हणी व त्यांचे अर्थ यांच्या अचूक जोड्या लावा.
5. **दैनिक ज्ञानचाचणी (Daily Quiz):** दररोज ५ प्रश्नांचे आव्हान आणि अचूकतेची टक्केवारी.

### ५. आवडत्या म्हणी (Offline Bookmarks & Export)
- ब्राऊझरमधील `localStorage` मध्ये १००% सुरक्षित बुकमार्किंग (कोणताही डेटा सर्व्हरवर ट्रॅक केला जात नाही).
- बुकमार्क केलेल्या म्हणींचे एका क्लिकवर JSON फॉरमॅटमध्ये बॅकअप डाऊनलोड करा किंवा आयात करा.
- सुंदर छापील पानासाठी सानुकूल प्रिंट व्ह्यू (Print View).

### ६. वाचन व उच्चार सहाय्यक (Audio Pronunciation & Dark Background)
- Web Speech API आधारित शुद्ध मराठी (`mr-IN` / `hi-IN`) ऑडिओ उच्चार.
- ॲनिमेटेड ऑडिओ वेव्ह व्हिज्युअलायझर.
- **रात्र वाचन मोड (Dark Background Mode):** रात्रीच्या किंवा कमी प्रकाशातील वाचनासाठी खास गडद पार्श्वभूमी पर्याय (`#0E121E` नाइट इंक व सोनेरी कडा). हेडर, मोबाईल मेनू आणि फुटरमधून एका क्लिकवर सुरू/बंद करता येते.

### ७. लोकसहभाग व पारदर्शक गुणवत्ता नियंत्रण (Community Collaboration)
- **म्हण सुचवा (`/suchva`):** लोकजीवनातील नवीन म्हणी सुचवण्यासाठी थेट देवनागरी पूर्वावलोकन (Live Preview) सह फॉर्म.
- **दुरुस्ती नोंदवा (`/durusti`):** शुद्धलेखन, अर्थ अथवा संदर्भात त्रुटी आढळल्यास त्वरित नोंदवण्याची सुविधा.

### ८. सुरक्षित संपादकीय कक्ष (Protected Admin Portal - `/admin`)
- गुप्त पासकी/टोकन सुरक्षा (डिफॉल्ट: `mhani2026`).
- प्रलंबित सूचना व दुरुस्त्यांची छाननी (Approve / Reject / Resolve).
- नवीन म्हण जोडणे व विद्यमान म्हणी संपादित करणे (स्थिर अनुक्रमांक अखंड राखला जातो).
- एका क्लिकवर संपूर्ण डेटाबेसचा **UTF-8 CSV** आणि **JSON** बॅकअप एक्सपोर्ट.

### ९. संपूर्ण शोध व एसईओ (SEO & Discoverability)
- देवनागरी व लॅटिन अक्षरांमध्ये झटपट शोध.
- `schema.org` DefinedTerm structured data (JSON-LD).
- सर्व १,००० म्हणी, १६ वर्गवाऱ्या आणि मुख्य पृष्ठांचे स्वयंचलित `sitemap.xml`.
- सर्वसमावेशक `robots.txt`.

## 🚀 सुरू करण्यासाठी (Getting Started)

### पूर्वतयारी (Prerequisites)
- **Node.js**: v18 किंवा नवीन (v20+ शिफारस केलेले)
- **npm**: v9 किंवा नवीन

### स्थापना (Installation)
```bash
# रिपॉझिटरी क्लोन करा किंवा फोल्डरमध्ये जा
cd Marathi

# अवलंबित्वे इन्स्टॉल करा
npm install
```

### डेव्हलपमेंट सर्व्हर (Run Locally)
```bash
npm run dev
```
ब्राऊझरमध्ये उघडा: [http://localhost:3000](http://localhost:3000)

### चाचण्या चालवा (Run Tests)
```bash
npm test
```
सर्व १५ युनिट व इंटिग्रेशन चाचण्या पार पडतील.

### प्रोडक्शन बिल्ड (Production Build)
```bash
npm run build
npm start
```

- वापरकर्त्याच्या ब्राऊझिंगवर कोणतेही ट्रॅकर्स, कुकीज किंवा ॲनॅलिटिक्स स्पायवेअर नाहीत.
